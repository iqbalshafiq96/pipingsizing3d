Continuity v = ṁ / (ρ·A), A = π·D²/4 Reynolds Re = ρ·v·D / μ → Laminar < 2300 < Transitional < 4000 < Turbulent Friction factor f = 64/Re (laminar); 1/√f = −2·log10( ε/(3.7D) + 2.51/(Re·√f) ) (Colebrook-White) Darcy-Weisbach ΔP_f = f·(L/D)·ρ·v²/2 Minor loss ΔP_k = K·ρ·v²/2, K = n·f_T (Crane TP-410), f_T = 0.25 / [log10(ε/3.7D)]² Static head ΔP_z = ρ·g·Δz (Δz = ±L vertical, user Δz for sloped horizontal runs) Energy balance P_out = P_in − ΔP_f − ΔP_k − ρ·g·Δz − ½ρ(v_out² − v_in²) Heat loss T_out = T_amb + (T_in − T_amb)·exp(−L / (R'·ṁ·cp)), R' = R_in + R_wall + R_ins + R_out Pressure effect gas: ΔT = μ_JT·ΔP (Joule-Thomson) liquid: ΔT = ΔP_loss / (ρ·cp) (friction heating) 3D coordinates E = +x, N = +y, Z = elevation [m]; fittings are zero-length points
